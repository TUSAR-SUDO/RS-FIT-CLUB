# RS Fit Club — what we still need from you

Everything on this list is currently a visible placeholder on the site (`[LIKE THIS]`). The site is
built so that nothing unverified is ever invented: while a value is missing, that element either
shows a token, hides itself, or shows an honest note. Send us the real value and it appears.

All of it lives in one file — `src/data/siteConfig.ts` — so nothing is buried in the design.

## 1. Contact (highest priority — these power every CTA)

- [ ] **Mobile number** for calls (`[PHONE NUMBER]`) — 10 digits, Indian mobile.
- [ ] **WhatsApp number** — can be the same number. Until it is supplied, the WhatsApp buttons are
      hidden on the hero, in the mobile menu and in the sticky bar, and the form's success panel
      offers no WhatsApp hand-off.
- [ ] **How fast do you call back?** (`[X HOURS]`) — e.g. "2 hours", "same day".
- [ ] **Email address** — we have `rsfitness@gmail.com` from your public listing. Confirm it is the
      address you want on the site, or send the correct one.
- [ ] **Opening hours** — per day (`[TIME]` × 3 rows). Only if you really are open all the time do
      we write "Always open".

## 2. Location

- [ ] **Exact street address / building** (`[STREET ADDRESS]`) and **PIN code** (`[PIN]`).
- [ ] **Google Maps** — either the lat/long, or the embed link for the shop listing.
- [ ] Is "Samantarapur, Mahavir Bazar, Bhubaneswar" the right way to describe the area publicly?

## 3. The owner (this section carries the most trust)

- [ ] **His name** (`[OWNER NAME]`) — and whether he wants it written in full or as "Coach __".
- [ ] **His story** — 2–3 short paragraphs, in his own words. Where he started, what he lifts, why
      this floor. Send it as voice notes if writing is a hassle; we'll shape it without changing
      the facts.
- [ ] **One line from him** for the pull-quote (`[OWNER QUOTE]`).
- [ ] **Certifications** (`[CERTIFICATION]`), **years on the floor** (`[YEARS ON THE FLOOR]`),
      and a **signature-style sign-off** if he has one.
- [ ] Confirmation that we may use the `OWNER_bg_REMOVED.png` cutout, and a second pose/photo if he
      has one (the founder section uses a second crop).

## 4. The team

- [ ] **Names** for 3 trainers + 1 nutritionist (`[TRAINER NAME]`).
- [ ] **Speciality** for each (`[SPECIALITY]`) — we pre-filled sensible ones (strength & conditioning,
      weight training, diet planning, Zumba & aerobics). Change them.
- [ ] **Certifications / qualifications** (`[CERTIFICATION]`, `[QUALIFICATION]`).
- [ ] **Photos** — portrait, shot straight on, dark or plain background. Vertical is best.

## 5. Membership

- [ ] **Plan names** — we guessed Monthly / Quarterly / Annual. Tell us what you actually sell.
- [ ] **Prices** — currently `[PRICE]`. Say the word and they go live; we never invent a rate.
- [ ] **What's included** in each plan, and which items are **add-ons** (marked `*` today:
      diet consults, personal training). The current list is our assumption, not your offer.
- [ ] Should any plan be flagged **"Most chosen"**?

## 6. Timetable

The days and class types are placeholders — only the _services_ are verified from your listing.

- [ ] **Times** for every slot (`[TIME]`).
- [ ] The real weekly pattern (which class runs on which day, and at what time).
- [ ] Are Zumba and Aerobics on the same day, or separate days?
- [ ] Anything seasonal or paused (`[TIME]`)? We'd rather print "on hold" than a wrong time.

## 7. Proof: numbers, reviews, transformations

- [ ] **Members on the floor**, **years running**, **coaches & nutritionists**, **sessions per week**.
      The counters only appear once these are real numbers — nothing gets rounded up for effect.
- [ ] **5 member reviews** — first name, goal, roughly how long they've trained, and what they said.
      We publish only what they actually said, with their permission.
- [ ] **Google reviews link** (and the star rating + review count if you have them).
- [ ] **Before/after photos (3 sets)** + written **consent** from each member, plus a first name, the
      goal, and how long it took.
- [ ] We will not publish stock photos or anyone else's transformations. If you'd rather not show
      before/afters at all, say so and we'll replace the section.

## 8. Photography

Every photo slot is a labelled placeholder frame that tells you what to shoot:

- [ ] **Gym floor, wide shot** (16:10) — lights on, golden hour if possible.
- [ ] **Equipment / action details** (square) — loaded bars, chalk, plates, the actual room.
- [ ] **Classes in motion** — Zumba and aerobics, a few frames.
- [ ] **Building / entrance** — so people recognise it from the road.

Consent: any photo with a member's face in it needs their OK.
